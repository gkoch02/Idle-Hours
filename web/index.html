Welcome to Idle Hours

This appliance picks a literary quote that mentions the current time and renders it to your eInk panel. Two minutes here gets you set up.

1 · Pick a theme

Each theme uses a different palette and typeface. Tap one to apply it.

2 · Quiet hours

—

The panel sleeps overnight by default (22:00–06:00). Adjust via --quiet-start / --quiet-end in the systemd unit if you want different times — runtime quiet-toggle is bound to the physical D button or the "Quiet / wake" control on the Now tab.

3 · You're done

Browse the four tabs (Now / Curate / Coverage / Activity) to manage quotes, search the corpus, and inspect telemetry. Press the button below to dismiss this wizard.

Controls

Mirrors the four physical Inky buttons. A render in flight returns 409 — taps during a refresh are dropped.

Preview themes

All registered themes rendered at the current time. Click a thumbnail to apply that theme.

Search corpus

Linear scan across the raw attributed corpus. Combine fields to narrow the result set.

Bucket inspector

Pick a bucket (or click a coverage cell) to see ranked candidates with full score breakdown. Lower is better at every position.

Selection overrides

Edits to assets/selection_overrides.json. Bans, boosts, preferred buckets, and per-row bans (ban_quote_keys). Server-validated — bad shapes return 400.

Content overrides

Per-row fixes layered onto the corpus by apply_content_overrides.py at bake time. After saving, click Bake now below to make the changes visible on the panel.

Re-bake quote database

Runs bake_quote_database.py in-process: re-applies the content-overrides sidecar to the raw corpus and writes assets/quote_database.jsonl. The runtime picker reads the new file on the next tick.

Coverage grid

144 buckets, one per (hour × minute-state). Cell colour encodes corpus row count. Tap to inspect.

empty 1–2 3–9 10+

Bucket gaps

Empty / sparse buckets with suggested phrases. Pass these to target_sparse_buckets.py or use them as harvester hints.
