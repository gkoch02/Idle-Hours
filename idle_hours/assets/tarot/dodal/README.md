# Jean Dodal tarot trumps

These twelve scans are trumps I–XII from Jean Dodal's *Tarot de Marseille*
(Lyon, 1701–1715). They are source artwork for the tarot theme's hour-mapped
illustrations and are kept together so build tooling can consume them without
mixing raw scans with generated runtime assets.

- Source: [Wikimedia Commons category](https://commons.wikimedia.org/wiki/Category:Tarot_de_Marseille_-_Jean_Dodal)
- Files: `trump_01.jpg` through `trump_12.jpg`
- Creator: Jean Dodal
